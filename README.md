# Python Data Analysis Projects

A collection of beginner-level data analysis projects built while learning Python.

## Projects

### 1. Student Performance Analyzer
Analyzed student marks using NumPy.

### 2. Netflix Data Analyzer
Explored the Netflix dataset using Pandas.

### 3. WhatsApp Chat Analyzer
Analyzed exported WhatsApp chat data using Pandas and NumPy.

### 4. Student Performance Visualization
Used Pandas and Matplotlib to visualize student performance.

### 5. Sleep vs Mobile Usage
Analyzed sleep hours and mobile usage using Pandas and Matplotlib.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib

## Purpose

These projects were created to practice Python programming, data manipulation, basic statistics, and data visualization.
