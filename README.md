# Python Data Analysis Projects

A collection of beginner-level data analysis projects built while learning Python, NumPy, Pandas, and Matplotlib.

## Projects

### 1. Student Performance Analyzer using NumPy

Analyzed student marks using NumPy and performed numerical calculations such as totals, averages, and performance analysis.

### 2. Netflix Data Analyzer

Explored and analyzed a Netflix dataset using Pandas.

**Dataset:** Obtained from Kaggle.

### 3. WhatsApp Chat Analyzer

Analyzed exported WhatsApp chat data using Pandas and NumPy to explore and understand chat information.

### 4. Student Performance Visualization using Matplotlib

Used Pandas and Matplotlib to analyze and visualize student performance through graphs and charts.

### 5. Sleep vs Mobile Usage Analysis

Analyzed the relationship between sleep hours and mobile usage using Pandas and Matplotlib.
